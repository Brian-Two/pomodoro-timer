# Pomodoro Timer

A minimal, modern Pomodoro timer built with plain HTML, CSS, and vanilla JavaScript.

- Large countdown display with a progress ring
- Custom duration: set any length from 1 to 180 minutes
- Start / Pause / Reset controls
- Plays a bell chime (Web Audio API) when the timer reaches zero
- Light and dark mode, mobile friendly

Open `index.html` in a browser to use it.
